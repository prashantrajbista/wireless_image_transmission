ADJSCC — Model Architecture

The complete convolutional autoencoder from arXiv:2012.00533, layer by layer, with a real CIFAR image traced through every stage — captured live from the trained C=16 checkpoint. See index.html for the interactive SNR explorer.

The whole network at a glance

Two mirrored CNNs with a noisy channel wedged between them. The encoder shrinks space and grows abstraction (3 colours → 16 learned feature channels); the channel normalizes power and adds noise; the decoder reverses the encoder to rebuild pixels. Every conv/deconv is followed by PReLU and an AF module that injects the SNR.

Channel block — no learned weights

z = flatten(code)                    # (B, 16·8·8) = (B, 1024)
z = z · sqrt(k / Σz²)                # power-normalize: mean power = 1
# read as 512 complex symbols (first 512 real, next 512 imag)
σ² = 1 / 10^(SNR/10);  y = z + N(0, σ²)      # AWGN
y → reshape (B, 16, 8, 8) → decoder

Pure math, fully differentiable — gradients flow back through the noise into the encoder, so the encoder learns a noise-robust code end to end. This is the only stochastic step.

Decoder — 5 transposed-conv layers (mirror)

y : (B, 16, 8, 8)
ConvT2d(16,  256, k5, s1, p2)               → PReLU → AF   # 8
ConvT2d(256, 256, k5, s1, p2)               → PReLU → AF   # 8
ConvT2d(256, 256, k5, s1, p2)               → PReLU → AF   # 8
ConvT2d(256, 256, k5, s2, p2, out_pad=1)    → PReLU → AF   # 8→16
ConvT2d(256, 3,   k5, s2, p2, out_pad=1)    → sigmoid       # 16→32
→ (B, 3, 32, 32)   # reconstruction in [0,1]

Same shapes as the encoder, run backwards: channels go 16→256→…→3, space goes 8→16→32. Final sigmoid clamps pixels into [0,1]. Note the decoder’s AF modules also receive the SNR — adaptation happens on the receive side too.

AF module — the SNR-conditioned gate (used 9×)

Inserted after every PReLU (5 in the encoder, 4 in the decoder). A squeeze-and-excitation block that mixes the feature summary with the channel SNR to produce a per-channel gate. 

ctx  = x.mean(dim=(H,W))            # (B, Ch)
gate = sigmoid(fc2(relu(fc1(cat([ctx, snr])))))   # (B, Ch), each in [0,1]
out  = x * gate[:, :, None, None]  # rescale each channel
Because the SNR is an input to all 9 gates, one weight set spans the whole 0–20 dB range — no per-SNR retraining. That single idea is the paper’s contribution; see it move on the interactive page.

End-to-end training

for each batch:
    snr  = uniform(0, 20)                 # random channel each step (ADJSCC)
    ĥ    = model(image, snr)             # enc → power-norm → AWGN → dec
    loss = MSE(ĥ, image)                 # pixel reconstruction only
    loss.backward()                       # grads flow through the noisy channel
  • No JPEG, no LDPC, no separate source/channel stages — one loss, learned jointly.
  • SNR sampled per step so the AF gates learn the full range; the baseline fixes it and drops AF.
  • Reported metrics: PSNR and single-scale SSIM.
